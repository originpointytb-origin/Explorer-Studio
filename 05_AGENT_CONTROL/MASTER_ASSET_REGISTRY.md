MASTER ASSET REGISTRY (MAR)
Purpose
The Master Asset Registry (MAR) is the official index of every approved asset within Explorer Studio.
Unlike the Master Asset Library, which defines governance, engineering, and standards, the Master Asset Registry records
the actual assets that exist.
Every approved production asset receives exactly one permanent registry entry.
The registry is the authoritative source for determining:
whether an asset exists,
•
where it is stored,
•
how it is classified,
•
what productions use it,
•
its approval status,
•
its technical state,
•
its reuse potential.
•
Registry Architecture
Every registered asset occupies one record.
The registry contains metadata only.
Detailed engineering remains in the Master Asset Specification.

Chief Production Architect Review
This is the first operational document built from the Master Asset Library standards.
The relationship between documents is now clear:
Master Asset Library (MAL) defines the rules.
•
Master Asset Registry (MAR) lists every approved asset.
•
Master Asset Specification (MAS) provides the detailed engineering record for each individual
asset.
•
That means Explorer Studio has moved from defining standards to managing real production
resources.
My recommendation before generating any assets
Do not start creating individual asset specifications one by one.
